# CaseLens — Judicial Intelligence Platform

## Setup
```
pip install -r requirements.txt
python scripts/seed.py
python scripts/train.py
uvicorn app.main:app --reload
```
Open http://localhost:8000

## Deploy on Render

1. Push this project to a GitHub repository.
2. In Render, choose **New +** → **Blueprint** and connect that repository.
3. Render will read `render.yaml` and create the CaseLens web service. Wait for the first build and deploy to finish, then open the service URL.
4. Check that the dashboard loads and that `/api/overview` returns JSON.

The Blueprint uses Render's free web-service plan. Its filesystem is temporary, so cases added in the app can be lost when the service restarts or redeploys. The first startup can also take a while while the database and search index initialize.

## Architecture
- **Backend**: FastAPI + uvicorn, Python 3.10+
- **Search**: sentence-transformers all-MiniLM-L6-v2, numpy cosine similarity, embeddings cached in data/embeddings.npy
- **Summarization**: Extractive — sentence embeddings, centroid proximity, keyword boosting
- **Prediction**: LightGBM regressor, features include both case metadata and precedent search signals
- **Storage**: SQLite (data/caselens.db) via stdlib sqlite3
- **Frontend**: Plain HTML + CSS + vanilla JS, no build step, served by FastAPI static files

## Data Note
Training labels are **synthetic**, generated by a documented formula in scripts/train.py. The model accepts real data: prepare a CSV with columns `case_type_encoded, days_since_filing, hearings_so_far, num_parties, is_appeal, top1_similarity, mean_top5_similarity, count_matches_above_threshold, similarity_spread, days_to_resolution` and retrain with `python scripts/train.py --data your_data.csv`.

## Plugging In Real Judgment Data
Use `python scripts/load_external.py --file judgments.csv --format csv`. The CSV must have columns: `id, title, court, year, case_type, text`. See script header for dataset sources.
